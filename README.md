# Дайджест: перформанс, ИИ-агенты, заработок на ИИ

Ежедневно в 09:00 МСК собирает вчерашний день с 362 источников, отбирает
6–8 кейсов с фактурой и публикует разбор в приватный канал Marktlytics.

## Файлы

| файл | что делает |
|---|---|
| `sources.yaml` | реестр источников: 172 телеграм-канала, 92 ютуб-канала, 77 RSS, 21 парсер |
| `harvest.py` | сбор за сутки, чистка, дедуп, предфильтр и скоринг |
| `discovery.py` | ежедневный поиск новых каналов через граф упоминаний, карантин |
| `publish.py` | публикация в Telegram с разбивкой по лимиту 4096 |
| `.env` | токен бота и id канала. В репозиторий не коммитить |
| `state/` | память: `seen.json` (30 дней хэшей), `discovery.json` (карантин) |
| `out/` | результаты прогона за день |

## Ежедневный цикл

```bash
python3 discovery.py --sources sources.yaml --state state --run   # ~4 мин
python3 harvest.py   --sources sources.yaml --state state --out out --workers 12   # ~40 сек
# → out/shortlist_YYYY-MM-DD.json читает модель, пишет digest.md
python3 publish.py --file digest.md
```

`harvest.py` за 40 секунд превращает 718 сырых записей в 168 строк для модели.
Ключевое: модель никогда не видит сырьё, только шортлист заголовков со
сниппетами. Транскрипты ютуба и полные тексты статей подтягиваются
точечно, уже после того как модель выбрала 6–8 победителей.

## Как устроен отбор

Предфильтр на регулярках делает три вещи и ни одной лишней.

Выбрасывает мусор: erid, вакансии, розыгрыши, анонсы вебинаров, «10 промптов
для ChatGPT». Определяет тему – перформанс, ИИ-агенты, заработок; запись без
темы не проходит вообще. И размечает `kind`: `case` если есть личный голос и
хотя бы две единицы фактуры, иначе `news`. Новости получают штраф, но не
выбрасываются – иногда апдейт площадки важнее любого кейса.

Скор считается так: ценность источника × 10, бонус 1.4 для малых авторских
каналов, плюс 6 за каждый маркер фактуры (цифры с рублями и процентами, CPL,
ROAS, ДРР, «потратил», «заработал»), минус 40 за «напиши текст нейросетью»,
минус 35 за корпоративную отчётность без личного участия.

Потолок 5 записей на источник – иначе Hugging Face с его 834 элементами
вытеснит всех остальных.

## Авто-пополнение базы

`discovery.py` каждый день обходит 40 источников из базы по ротации (сид от
даты, поэтому прогон воспроизводим) и собирает упоминания и репосты. Репост
весит втрое больше упоминания: автор сознательно ретранслирует.

Новичок садится в карантин на 7 дней. Там считаются доля рекламы, средняя
длина поста и доля постов с конкретикой. Через неделю либо повышение в базу,
либо отсев с записанной причиной, чтобы не проверять одно и то же дважды.

Проверено на живом прогоне: 40 сидов → 92 кандидата → 33 в карантин.
Среди найденных `@uxhorn` (средний пост 3200 знаков, конкретика 79%),
`@digital_expertise` (70%), `@krasnodar_digital` на 265 подписчиков (69%).

## Ютуб

RSS без ключа: `youtube.com/feeds/videos.xml?channel_id=UC...`, 15 последних
видео, Shorts в той же ленте.

Транскрипты только через `yt-dlp`. Библиотека `youtube-transcript-api` в
облаке нежилец – отдаёт результат один раз, потом IP получает постоянный бан.
Рабочая команда:

```bash
yt-dlp --write-auto-sub --write-sub --sub-lang ru,en --skip-download \
       --sub-format vtt -o "%(id)s.%(ext)s" "https://www.youtube.com/watch?v=ID"
# при "Sign in to confirm you're not a bot":
yt-dlp --extractor-args "youtube:player_client=web_embedded" \
       --ignore-no-formats-error --write-auto-sub --sub-lang ru,en \
       --skip-download --sub-format vtt -o "%(id)s.%(ext)s" "URL"
```

VTT надо чистить: снять теги `<c>`, тайминги и дедуплицировать строки.
Сырой файл завышен примерно в десять раз (59 КБ → 5,2 КБ текста).

Держать 2–3 секунды между запросами к `youtube.com/watch`. RSS-эндпоинт
намного либеральнее – 470 запросов подряд прошли без ошибок.

## Развёртывание

Контейнер, в котором всё это писалось, живёт до конца сессии. Ежедневная
задача стартует в новом окружении, поэтому проект должен лежать снаружи –
в приватном гит-репозитории. Клонирование по HTTPS из облака проверено,
работает.

Каждое утро задача клонирует репозиторий, ставит `pyyaml` и `yt-dlp`,
прогоняет цикл, коммитит обновлённый `state/` обратно. Так дедуп за 30 дней
и карантин переживают перезапуск.

## Ограничения, о которых надо помнить

Приватные телеграм-каналы и каналы с выключенным веб-превью не читаются
никак – это ограничение самого Telegram, а не сборщика. `@zuevichigor` из
этой категории.

Примерно 5–10% роликов на ютубе не отдают субтитры даже через `yt-dlp`.
Для них конвейер откатывается на заголовок и описание.

Сайты без RSS собираются в отдельный индекс `webindex_*.json` – там только
ссылки, без дат и текста. Модель ходит туда точечно, когда шортлист выглядит
пустовато.
